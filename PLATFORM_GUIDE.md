# React Learning Platform

A comprehensive, interactive learning platform for mastering React from fundamentals to advanced concepts.

## Features

### 1. **Structured Learning Path**
- 18 comprehensive lessons following the official React roadmap
- Covers everything from JavaScript fundamentals to deployment and production
- Each lesson includes:
  - Detailed overview and key concepts
  - Interactive code examples with syntax highlighting
  - Key points and learning takeaways
  - Lesson completion tracking

### 2. **Interactive Code Editor**
- Built-in code editor (CodeMirror integration) for hands-on learning
- Live code examples in lessons
- Syntax highlighting for JavaScript/JSX
- Write and test code directly within lessons

### 3. **Three-Part Practice System**
- **Quizzes**: Multiple-choice questions to test understanding
  - Immediate feedback on answers
  - 80% pass requirement for completion
  - Covers each lesson's key concepts

- **Coding Challenges**: Progressive difficulty coding problems
  - Problem descriptions and starter code
  - Test cases to validate solutions
  - Immediate feedback on correctness

- **Projects**: Full-scale real-world building projects
  - Comprehensive requirements
  - Starter code templates
  - Resource links for guidance
  - Build portfolio-worthy applications

### 4. **GitHub-Style Contribution Calendar**
- Visual tracking of daily learning activity
- Color-coded intensity levels (0-4 levels of engagement)
- Hover tooltips showing learning minutes per day
- Statistics dashboard showing:
  - Total learning minutes
  - Current learning streak (consecutive days)
  - Longest streak (personal record)
  - Days active with average minutes per day
- Interactive date selection to view detailed daily progress

### 5. **Dashboard & Progress Tracking**
- Overview of your learning journey
- Visual progress bars for each lesson
- Quick access to all platform features
- Summary statistics

## Navigation

The platform includes a top navigation bar with quick links:
- **Dashboard**: View your learning progress overview
- **Lessons**: Access structured learning content
- **Practice**: Complete quizzes, challenges, and projects
- **Calendar**: Track daily learning activity

## Learning Curriculum (18 Topics)

1. **JavaScript Fundamentals** - Variables, functions, ES6 features
2. **React Fundamentals** - JSX, components, useState hook
3. **JSX & Rendering** - Syntax rules and element rendering
4. **Components** - Functional components and composition
5. **Props** - Data passing between components
6. **State Management** - useState hook and state updates
7. **Event Handling** - User interactions and forms
8. **Conditional Rendering** - if/else and ternary operators
9. **Lists & Keys** - Rendering and optimizing lists
10. **Side Effects** - useEffect hook and lifecycle
11. **Routing** - Client-side navigation with React Router
12. **Forms & Validation** - Form handling and validation
13. **Advanced State** - Context API and complex state
14. **API Integration** - Fetching data and HTTP requests
15. **Performance Optimization** - useMemo, useCallback, React.memo
16. **Custom Hooks** - Creating reusable hook logic
17. **Project Architecture** - Scalable app structure
18. **Deployment** - Build and deploy to production

## Technology Stack

- **Frontend**: Next.js 16 with React 19
- **Styling**: Tailwind CSS v4
- **Code Editor**: CodeMirror 6
- **UI Components**: shadcn/ui
- **Icons**: lucide-react
- **Date Handling**: date-fns
- **Backend**: API routes (Next.js)
- **Database**: MongoDB (optional for persistence)

## Getting Started

1. **Visit Lessons**: Click "Start Learning" to begin with JavaScript Fundamentals
2. **Read & Learn**: Each lesson includes overview, code examples, and key concepts
3. **Practice**: Test your knowledge with quizzes, challenges, and projects
4. **Track Progress**: Use the calendar to maintain a consistent learning streak
5. **Monitor Stats**: Check your dashboard for overall progress

## How to Use Each Feature

### Lessons
- Select a lesson from the sidebar
- Read the overview and key concepts
- Review the code examples in the editor
- Mark lesson as complete when done

### Practice
- Navigate to practice section
- Choose between quizzes, challenges, or projects
- For quizzes: Answer all questions and submit
- For challenges: Edit starter code and verify against test cases
- For projects: Follow requirements and build complete applications

### Calendar
- View your monthly learning activity
- Click on any day to see detailed activity information
- Monitor your current streak and personal record
- Track average learning minutes per day

## Tips for Success

1. **Consistency**: Try to learn something every day to build streaks
2. **Complete Lessons First**: Work through lessons sequentially for better understanding
3. **Practice Actively**: Don't just read - code along with examples
4. **Start with Quizzes**: Solidify understanding before tackling challenges
5. **Build Projects**: Real-world projects cement your learning
6. **Track Progress**: Use the calendar to stay motivated

## Notes

- All progress is tracked in the application
- Code examples can be modified and tested in the editor
- Quizzes require 80% to be marked complete
- Projects are self-paced with no time limits
- The calendar provides visual motivation through streaks
