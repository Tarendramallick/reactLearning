## ⚡ Super Quick Start

**Prerequisites:**
- Node.js 18+
- MongoDB (Atlas or local)
- pnpm (or npm/yarn)

**Steps:**

```bash
# 1. Install dependencies
pnpm install

# 2. Create .env.local
echo "MONGODB_URI=your-connection-string" > .env.local

# 3. Start dev server
pnpm dev

# 4. Open browser
# http://localhost:3000

# 5. Sign up and start learning!
```

**That's it!** ✅

## 🎯 Common Questions

### Q: How do I add more lessons?
**A:** Edit `lib/lessonsData.ts` - add to the LESSONS array

### Q: Can I customize the branding?
**A:** Yes! Modify Navbar, logo, and colors in components

### Q: How do I change the passing score?
**A:** Edit `lib/quizzesData.ts` - change `passingScore` value

### Q: Where is user data stored?
**A:** MongoDB collections: users, user_progress, quiz_attempts

### Q: Is this production ready?
**A:** Yes! Deploy to Vercel with one click

### Q: Can I add more quizzes?
**A:** Yes! Edit `lib/quizzesData.ts` - add to QUIZZES array
